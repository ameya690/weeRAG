# weeRAG Interactive Demo

Compare **dense**, **hybrid (RRF)**, and **cross-encoder reranked** retrieval side by side with latency and pipeline traces.

Built entirely from scratch using [weeRAG](https://github.com/ameya690/weeRAG) — small, readable implementations of LLM and RAG building blocks.

No model downloads or API keys required — uses a built-in corpus with deterministic hash-based embeddings.
